wholeseek — a minimal Soulseek client for music
https://github.com/Utility-Gods/wholeseek

Install for your user (no root needed):
    ./install.sh
Remove again:
    ./install.sh --uninstall
Or just run ./wholeseek from this folder.

Needs glibc and ALSA (libasound.so.2), present on practically every desktop
distribution. Licensed under the MIT license (see LICENSE).
